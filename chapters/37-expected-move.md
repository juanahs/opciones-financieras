# Capítulo 37

# Expected Move

---

# Introducción

El mercado de opciones no solo fija precios.

También incorpora expectativas sobre la magnitud del movimiento futuro.

Una de las herramientas más utilizadas para estimarlo es el **Expected Move**.

---

# ¿Qué es?

Es una estimación probabilística del rango de movimiento esperado para un periodo determinado.

No es una predicción.

No indica dirección.

Indica amplitud.

---

# Ejemplo

```
Precio

100 €

Expected Move

±5 €
```

El mercado considera razonable un rango aproximado entre:

```
95 €

↓

105 €
```

---

# Aplicaciones

El Expected Move resulta especialmente útil para:

- seleccionar Strikes;
- vender Covered Calls;
- vender Cash Secured Puts;
- construir Iron Condors;
- preparar estrategias antes de resultados.

---

---

# Interpretación

```
Expected Move

Muy pequeño

↓

Mercado tranquilo.

----------------------------

Expected Move

Muy grande

↓

Mercado nervioso.
```

---

# Integración con Swing Trading

Si el objetivo técnico está muy por encima del Expected Move para el vencimiento elegido, quizá sea conveniente utilizar un vencimiento más lejano.

---

# Error habitual

Confundir el Expected Move con un objetivo de precio.

No lo es.

Se trata únicamente de una estimación estadística.

---

# Checklist

□ Conozco el Expected Move.

□ Es coherente con mi estrategia.

□ No lo interpreto como una predicción.

---

# Conclusión

El Expected Move permite adaptar mejor los Strikes y los vencimientos al riesgo descontado por el mercado.
