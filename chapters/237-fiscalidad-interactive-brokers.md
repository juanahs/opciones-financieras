# Capítulo 237 — Fiscalidad e Interactive Brokers



---

# Introducción

Interactive Brokers proporciona una documentación muy completa de todas las operaciones realizadas.

Estos informes resultan esenciales para elaborar correctamente la declaración fiscal.

---

# Informes útiles

- Activity Statement.
- Trade Confirmation.
- Realized Summary.
- Dividend Report.
- Interest Report.

---

# Información recomendable

Conservar cada año.

```
Activity Statement

↓

Trades

↓

Options

↓

Commissions

↓

Corporate Actions
```

---

# Exportación

Interactive Brokers permite exportar los movimientos en distintos formatos.

Resulta recomendable conservar una copia anual.

---

# Organización

Crear una carpeta por ejercicio fiscal.

```
2026

↓

Opciones

↓

Acciones

↓

Dividendos

↓

Intereses
```

---

# Conclusión

Una correcta organización documental reduce significativamente el tiempo necesario para preparar la información fiscal.
