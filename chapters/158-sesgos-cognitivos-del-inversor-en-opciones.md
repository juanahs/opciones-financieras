# Capítulo 158 — Sesgos Cognitivos del Inversor en Opciones



---

# Introducción

Las opciones financieras no solo ponen a prueba el conocimiento técnico.

También exponen con gran intensidad los sesgos psicológicos del ser humano.

Conocer estos sesgos permite reconocerlos antes de que afecten a las decisiones.

---

# Sesgo de confirmación

Buscar únicamente información que apoye nuestra idea.

Ejemplo.

```
Quiero vender una Put

↓

Solo leo argumentos alcistas
```

---

# Exceso de confianza

Tras una serie de operaciones exitosas.

```
Aumentar tamaño

↓

Reducir disciplina

↓

Incrementar riesgo
```

---

# Aversión a las pérdidas

```
Cerrar beneficios rápido

↓

Mantener pérdidas demasiado tiempo
```

Es uno de los comportamientos más frecuentes.

---

# FOMO

Fear Of Missing Out.

```
Movimiento fuerte

↓

Entrar tarde

↓

Pagar primas elevadas
```

---

# Anclaje

Tomar decisiones basándose en un precio pasado.

Ejemplo.

```
"Antes cotizaba a 300."

↓

"Ahora está barata."
```

Sin analizar el contexto.

---

# Recencia

Otorgar demasiado peso a los acontecimientos más recientes.

---

# Sesgo del coste hundido

```
"He pagado mucho por esta LEAPS.

No puedo vender."
```

El mercado no conoce nuestro precio de compra.

---

# Ilusión de control

Creer que utilizar estrategias complejas implica automáticamente mayor probabilidad de éxito.

---

# Cómo combatirlos

Crear procedimientos.

```
Checklist

↓

Proceso

↓

Disciplina

↓

Revisión
```

---

# Conclusión

El conocimiento técnico reduce errores de cálculo.

Los procesos reducen errores psicológicos.

Ambos son imprescindibles.
