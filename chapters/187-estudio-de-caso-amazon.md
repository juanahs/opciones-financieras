# Capítulo 187 — Caso de Estudio: Amazon

---

# Introducción

Amazon constituye un ejemplo excelente para estudiar cómo adaptar las estrategias con opciones a una empresa con elevada calidad, crecimiento estructural y periodos alternos de fuerte volatilidad.

No todas las fases del gráfico justifican la misma estrategia.

---

# Perfil

| Factor | Evaluación |
|---------|------------|
| Liquidez | Excelente |
| Mercado de opciones | Excelente |
| Volatilidad | Media-Alta |
| Tendencias largas | Frecuentes |
| Adecuada para LEAPS | Muy alta |

# Escenario 3

---

# Riesgos

Amazon suele reaccionar intensamente durante:

- Earnings.
- Noticias sobre consumo.
- Cambios en AWS.
- Decisiones regulatorias.

---

# Enseñanza

La calidad empresarial no elimina la necesidad de esperar un buen contexto técnico.

---

# Conclusión

Amazon es un excelente candidato para LEAPS y CSP cuando el gráfico ofrece una relación riesgo-beneficio favorable.
