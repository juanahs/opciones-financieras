# Capítulo 69 — Portfolio Margin



---

# Introducción

Portfolio Margin representa un sistema avanzado de cálculo de garantías.

A diferencia del Margin tradicional, no evalúa únicamente cada posición de forma independiente.

Analiza el riesgo conjunto de toda la cartera.

Este enfoque suele resultar mucho más eficiente para inversores diversificados.

---

# Objetivos

- Comprender el funcionamiento del Portfolio Margin.
- Identificar sus ventajas.
- Conocer sus limitaciones.
- Saber cuándo resulta apropiado.

---

# Margin tradicional

```
Posición A

↓

Garantía

+

Posición B

↓

Garantía

+

Posición C

↓

Garantía
```

Cada posición se analiza de forma relativamente independiente.

---

# Portfolio Margin

```
Cartera completa

↓

Escenarios

↓

Riesgo agregado

↓

Garantía
```

El sistema reconoce coberturas naturales entre posiciones.

---

# Ejemplo

Supongamos:

- Acciones de Microsoft.
- Protective Put.
- Covered Call.

El riesgo conjunto puede ser inferior al riesgo de cada posición analizada por separado.

---

# Ventajas

- utilización más eficiente del capital;
- reconocimiento de coberturas;
- mejor adaptación a carteras complejas.

---

# Riesgos

Una menor exigencia de garantías no significa que el patrimonio sea menos arriesgado.

Puede inducir a aumentar excesivamente el tamaño de las posiciones.

---

# ¿Quién debería utilizarlo?

Principalmente:

- inversores experimentados;
- carteras amplias;
- múltiples estrategias simultáneas.

No suele ser necesario para quien únicamente vende una Cash Secured Put ocasionalmente.

---

# Checklist

□ Comprendo el riesgo agregado.

□ La cartera está diversificada.

□ No dependo del apalancamiento.

□ Existen coberturas reales.

---

# Conclusión

Portfolio Margin recompensa la correcta gestión del riesgo.

No sustituye la disciplina.
