# Capítulo 168 — Framework VSA Aplicado a Opciones



---

# Introducción

El análisis VSA (Volume Spread Analysis) permite interpretar el equilibrio entre oferta y demanda mediante la relación entre volumen y rango de las velas.

Integrado con opciones, proporciona un filtro adicional para seleccionar el momento de entrada.

---

# Principio básico

Las opciones no deben ignorar el volumen.

El volumen suele anticipar la intención de los grandes participantes.

---

# Caso 1

## No Supply

```
Caída

↓

Poco volumen

↓

Oferta agotándose
```

Puede favorecer.

- CSP.
- LEAPS.

---

# Caso 2

## No Demand

```
Subida

↓

Poco volumen
```

Evitar perseguir el precio.

Esperar confirmación.

---

# Caso 3

## Stopping Volume

Volumen extraordinariamente elevado tras una caída.

Analizar junto con Wyckoff.

Puede anticipar.

```
Spring

↓

Test
```

---

# Caso 4

## Effort vs Result

```
Mucho volumen

↓

Poco avance
```

Puede indicar absorción.

No abrir posiciones únicamente porque exista un fuerte volumen.

Interpretar el contexto.

---

# Caso 5

## Climactic Action

Los movimientos extremadamente acelerados suelen aumentar:

- IV;
- riesgo emocional;
- probabilidad de decisiones impulsivas.

---

# Árbol operativo

```
VSA

↓

↓

↓

```

---

# Conclusión

VSA no sustituye al análisis de volatilidad.

Lo complementa.

Permite comprender mejor cuándo la actividad institucional respalda una hipótesis antes de seleccionar la estrategia con opciones.
