# Capítulo 28

# Cómo seleccionar el vencimiento

---

# Introducción

Elegir correctamente el vencimiento es una de las decisiones más importantes en cualquier estrategia con opciones.

Muchos errores no provienen del Strike.

Provienen del tiempo.

---

# El tiempo es un activo

Cada día transcurrido modifica el precio de una opción.

No todos los vencimientos evolucionan igual.

```
Mucho tiempo

↓

Theta lenta

-----------------------

Poco tiempo

↓

Theta acelerada
```

---

# Factores a considerar

Antes de elegir un vencimiento pregúntese:

- ¿Cuál es mi horizonte temporal?
- ¿Qué estructura técnica estoy operando?
- ¿Cuándo espero que ocurra el movimiento?
- ¿Existen resultados empresariales?
- ¿Habrá pago de dividendos?

---

# Vencimientos cortos

Ventajas

- Theta elevada.
- Mayor rotación.
- Menor coste absoluto.

Inconvenientes

- Poco margen para que el análisis técnico se desarrolle.
- Mayor Gamma.
- Menor capacidad de reacción.

---

# Vencimientos largos

Ventajas

- Más tiempo para que el escenario se cumpla.
- Menor deterioro diario.
- Mayor estabilidad.

Inconvenientes

- Mayor desembolso.
- Mayor exposición a Vega.

---

# Relación con estrategias

| Estrategia | Vencimiento habitual |
|------------|----------------------|
| Covered Call | Corto |
| Cash Secured Put | Corto-Medio |
| LEAPS | Largo |
| PMCC | LEAPS + Corto |
| Protective Put | Según el periodo a cubrir |

---

# Integración con Swing Trading

Si el análisis técnico anticipa un movimiento que suele desarrollarse durante varias semanas, utilizar un vencimiento de apenas unos días puede introducir un riesgo innecesario.

El vencimiento debe conceder tiempo suficiente para que la hipótesis tenga oportunidad de cumplirse.

---

# Regla práctica

Nunca elija el vencimiento únicamente porque la prima sea más barata.

El tiempo también forma parte del activo que está comprando.

---

# Checklist

□ Horizonte temporal definido.

□ Eventos próximos revisados.

□ Theta aceptable.

□ Vega asumible.

□ Liquidez suficiente.

---

# Conclusión

La mejor estrategia puede fracasar simplemente por utilizar un vencimiento inadecuado.

El tiempo debe seleccionarse con el mismo cuidado que el Strike.
