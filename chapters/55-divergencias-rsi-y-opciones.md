# Capítulo 55 — Divergencias RSI y Selección de Estrategias



---

# Introducción

Las divergencias del RSI no constituyen señales de compra o venta por sí mismas.

Representan una pérdida de impulso.

Su utilidad aumenta cuando coinciden con:

- soportes;
- resistencias;
- Wyckoff;
- VSA.

Las opciones deben seleccionarse únicamente después de validar el contexto.

---

# Divergencia alcista

```
Precio

↓

Nuevo mínimo

RSI

↓

Mínimo superior
```

Indica debilitamiento de la presión vendedora.

---

# Estrategias posibles

Si existe confirmación:

- Compra directa.
- LEAPS.
- Cash Secured Put.

---

# Divergencia bajista

```
Precio

↓

Nuevo máximo

RSI

↓

Máximo inferior
```

No implica necesariamente vender.

Puede justificar:

- reducir Covered Calls agresivas;
- proteger cartera;
- esperar.

---

# Integración

```
Divergencia

+

Spring

+

Stopping Volume

↓

Mayor confianza
```

Una señal aislada nunca debería justificar una estrategia con opciones.

---

# Error frecuente

Comprar Calls únicamente porque aparece una divergencia.

Debe existir confirmación mediante el precio.

---

# Conclusión

El RSI ayuda a estimar el impulso.

El precio continúa teniendo la última palabra.
