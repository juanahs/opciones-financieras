# Capítulo 146 — El Ciclo Completo de una Operación Profesional



# Introducción

Una operación profesional no comienza cuando se envía una orden.

Comienza mucho antes.

Y tampoco termina cuando la posición se cierra.

Finaliza únicamente cuando el gestor ha revisado el resultado y ha extraído conclusiones para mejorar el siguiente proceso.

El verdadero activo de un gestor no es una operación.

Es su proceso.

# El ciclo completo

```
Observación

↓

Selección

Análisis

Planificación

Ejecución

Seguimiento

Salida

Revisión

Aprendizaje
```

# Fase 1

## Observación

No buscar operaciones.

Buscar empresas excelentes.

El universo inicial debería estar formado por compañías que estaríamos encantados de mantener durante muchos años.

# Fase 2

## Selección

Filtrar únicamente aquellas empresas que presenten:

- tendencia favorable;
- liquidez suficiente;
- opciones líquidas;
- contexto técnico claro.

# Fase 3

## Análisis

Debe incluir:

- estructura del mercado;
- Wyckoff;
- VSA;
- RSI;
- medias móviles;
- volatilidad;
- calendario de eventos.

# Fase 4

## Planificación

Antes de abrir la posición debe quedar definido:

- estrategia;
- Strike;
- vencimiento;
- tamaño;
- riesgo máximo;
- plan de salida.

# Fase 5

## Ejecución

La orden debe limitarse a ejecutar un plan ya diseñado.

Nunca debe modificarse el plan durante la introducción de la orden.

# Fase 6

## Seguimiento

Revisar únicamente aquello que pueda invalidar la hipótesis.

No monitorizar el precio constantemente.

# Fase 7

## Salida

La salida debe producirse porque:

- se alcanzó el objetivo;
- cambió la tesis;
- apareció una mejor alternativa;
- el riesgo dejó de compensar.

# Fase 8

## Revisión

Responder siempre.

```
¿Qué hice bien?

¿Qué hice mal?

¿Qué repetiré?

¿Qué evitaré?
```

# Conclusión

Las operaciones generan beneficios.

Los procesos generan carreras profesionales.

# Psicología del Operador de Opciones

Después de cientos de páginas dedicadas a estrategias, Greeks, volatilidad y gestión del riesgo, aparece un aspecto que suele recibir mucha menos atención y, sin embargo, determina una gran parte de los resultados obtenidos.

La psicología.

Las opciones magnifican las emociones porque permiten obtener beneficios o pérdidas importantes utilizando relativamente poco capital.

Precisamente por ello exigen una disciplina superior a la necesaria para comprar acciones.

# La ilusión del control

Las opciones ofrecen decenas de combinaciones posibles.

Esto genera una sensación engañosa.

```
Más estrategias

Mayor control
```

La realidad es distinta.

Más decisiones

Más errores potenciales
```

# El exceso de confianza

Después de varias operaciones consecutivas con beneficio suele aparecer una sensación peligrosa.

```
"He encontrado un sistema."
```

Normalmente esto conduce a:

- aumentar tamaño;
- asumir más riesgo;
- reducir disciplina.

# El miedo al Assignment

Muchos inversores consideran el Assignment como un fracaso.

En realidad:

```
Cash Secured Put

Assignment

Compra de acciones
```

Si ese era el objetivo inicial, el Assignment representa exactamente el éxito del plan.

# El miedo a perder una subida

La Covered Call genera un conflicto psicológico habitual.

```
Prima cobrada

Mercado continúa subiendo
```

El inversor siente que ha cometido un error.

No necesariamente.

Debe recordar que:

La operación se diseñó con un beneficio máximo previamente aceptado.

# La obsesión por cerrar pronto

Otro comportamiento frecuente.

```
Pequeño beneficio

Cerrar inmediatamente
```

Mientras tanto:

```
Pérdidas

Esperar demasiado
```

Este comportamiento deteriora la esperanza matemática de cualquier sistema.

# La disciplina

Los mejores gestores no poseen una capacidad especial para predecir el mercado.

Poseen una extraordinaria capacidad para ejecutar el mismo proceso una y otra vez.

La psicología no sustituye al análisis.

Pero un excelente análisis ejecutado sin disciplina termina produciendo resultados mediocres.
