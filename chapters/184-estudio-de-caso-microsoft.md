# Introducción

Microsoft representa uno de los mejores ejemplos de empresa para un inversor de largo plazo que desea complementar su cartera mediante opciones.

Su elevada liquidez, estabilidad del negocio y profundidad del mercado de derivados la convierten en un excelente laboratorio para aplicar procesos profesionales.

# Escenario C

## Sobreextensión

Después de una subida muy acelerada.

Evitar.

- perseguir el precio;
- comprar Calls OTM de corto plazo.

- esperar;
- Covered Call si ya se poseen acciones.
