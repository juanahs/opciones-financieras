# Capítulo 217 — Capítulo 217

# Glosario Profesional (K-L)

---

# LEAPS

Long-Term Equity Anticipation Securities.

Opciones con vencimientos muy largos, normalmente superiores a un año.

Se utilizan frecuentemente como sustituto parcial de las acciones.

---

# Leg

Cada una de las posiciones individuales que forman una estrategia compleja.

Ejemplo.

```
Bull Put Spread

↓

Leg 1

Put vendida

+

Leg 2

Put comprada
```

---

# Limit Order

Orden que establece el precio máximo de compra o mínimo de venta aceptado por el inversor.

Es el tipo de orden recomendado para negociar opciones.

---

# Liquidity

Facilidad para comprar o vender contratos sin afectar significativamente al precio.

Se evalúa mediante.

- volumen;
- Open Interest;
- Bid-Ask Spread.

---

# Long Call

Compra de una Call.

Proporciona exposición alcista con riesgo limitado a la prima pagada.

---

# Long Put

Compra de una Put.

Permite beneficiarse de caídas del activo o proteger una posición existente.

---

# Long Straddle

Compra simultánea de una Call y una Put con el mismo Strike y vencimiento.

Busca grandes movimientos en cualquier dirección.

---

# Long Strangle

Compra simultánea de una Call y una Put con distintos Strikes.

Menor coste que un Straddle.

Mayor movimiento necesario para obtener beneficios.

---

# Conclusión

Los conceptos de este bloque constituyen la base operativa de muchas estrategias modernas con opciones.
