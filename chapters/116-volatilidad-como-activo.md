# Capítulo 116 — Capítulo 116

# La Volatilidad como un Activo

---

# Introducción

El mayor cambio de mentalidad que debe realizar un inversor en opciones consiste en dejar de considerar que únicamente opera acciones.

En realidad opera dos activos simultáneamente.

```
Activo 1

↓

La acción

----------------

Activo 2

↓

La volatilidad
```

Las opciones cotizan sobre ambos.

No basta con acertar la dirección del precio.

También es necesario comprender cómo evoluciona la volatilidad implícita.

---

# Dos operaciones simultáneas

Cuando compras una Call no solo estás comprando una expectativa alcista.

También estás comprando volatilidad.

Cuando vendes una Put no solo estás aceptando comprar acciones.

También estás vendiendo volatilidad.

---

# Analogía

Imagina comprar un seguro para un coche.

El precio del seguro depende de:

- el valor del coche;
- la probabilidad de accidente.

Con las opciones ocurre algo parecido.

```
Precio acción

+

Volatilidad

↓

Prima
```

---

# Dos mercados diferentes

El mercado puede mostrar:

```
Acción

↑

Volatilidad

↓

----------------

Acción

↓

Volatilidad

↑

----------------

Acción

↑

Volatilidad

↑

----------------

Acción

↓

Volatilidad

↓
```

Cada combinación afecta de forma distinta al valor de las opciones.

---

# Error habitual

Muchos inversores piensan:

```
"La acción ha subido.

Mi Call debería subir."
```

No necesariamente.

Si la volatilidad cae con fuerza, parte del beneficio puede desaparecer.

---

# Aplicación práctica

Antes de abrir cualquier posición conviene responder:

```
¿Estoy comprando volatilidad?

↓

¿Estoy vendiendo volatilidad?

↓

¿Me interesa hacerlo ahora?
```

---

# Conclusión

El inversor profesional no opera únicamente acciones.

Opera precio y volatilidad de forma simultánea.
