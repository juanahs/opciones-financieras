# Capítulo 173

# Framework Profesional para Gestionar un Assignment

---

# Introducción

El Assignment es uno de los conceptos que más inquietud genera entre quienes comienzan a utilizar opciones.

En realidad, un Assignment no constituye un problema.

Únicamente representa un cambio en la naturaleza de la posición.

Un gestor profesional nunca improvisa cuando se produce.

Ya conoce exactamente qué hará.

---

# Assignment en una Put

```

Assignment

Compra de acciones
```

Preguntas.

- ¿Era el objetivo inicial?
- ¿Dispongo del efectivo necesario?
- ¿Sigue siendo válida la tesis?

# Assignment en una Call

```
Covered Call

↓

Assignment

↓

```

Responder.

- ¿Aceptaba vender a ese precio?
- ¿Deseo recomprar?
- ¿Existe otra oportunidad mejor?

---

# Aspecto psicológico

El Assignment no debe interpretarse como una pérdida de control.

En la mayoría de estrategias conservadoras forma parte del diseño original.

---

# Error frecuente

Intentar evitar cualquier Assignment.

Muchas veces esa decisión empeora el resultado económico.

---

# Conclusión

La mejor gestión del Assignment comienza antes de vender la opción.

Si el Assignment no resulta aceptable, la operación tampoco debería abrirse.
