# Capítulo 24

# Backspread

---

# Introducción

El Backspread invierte la lógica del Ratio Spread.

Se compran más opciones de las que se venden.

Ejemplo:

```
Vender

1 Call

↓

Comprar

2 Calls
```

---

# Filosofía

El objetivo consiste en beneficiarse de movimientos muy violentos.

Especialmente cuando:

- la volatilidad implícita es relativamente baja;
- se espera una expansión extraordinaria.

---

# Escenario

```
Compresión

↓

Ruptura explosiva

↓

Backspread
```

---

# Ventajas

- Gran potencial de beneficio.
- Riesgo limitado en determinadas configuraciones.
- Muy útil antes de expansiones excepcionales.

---

# Inconvenientes

- Baja probabilidad.
- Gestión compleja.
- Difícil selección de Strikes.

---

# Conclusión

Para un inversor patrimonial constituye una estrategia especializada reservada para escenarios muy concretos.
