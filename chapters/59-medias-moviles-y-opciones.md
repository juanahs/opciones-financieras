# Capítulo 59

# Medias Móviles y Selección de Estrategias con Opciones

---

# Introducción

Las medias móviles son una de las herramientas más utilizadas por los inversores de Swing Trading para identificar la dirección predominante del mercado.

Por sí solas no generan una ventaja estadística sostenible.

Sin embargo, combinadas con estructura de mercado, volumen, Wyckoff y VSA permiten clasificar el contexto y seleccionar estrategias con opciones mucho más coherentes.

Las opciones no sustituyen a las medias móviles.

Las utilizan como filtro.

---

# Objetivos

Al finalizar este capítulo el lector será capaz de:

- Interpretar correctamente las medias móviles.
- Relacionarlas con el contexto de mercado.
- Seleccionar estrategias acordes con la tendencia.
- Evitar utilizar opciones contra la tendencia principal.

---

# Filosofía

La media móvil no predice.

Describe.

Su utilidad consiste en responder:

> ¿Cuál es la dirección dominante del mercado?

---

# Medias más utilizadas

En Swing Trading suelen emplearse:

| Media | Uso habitual |
|---------|--------------|
| EMA 20 | Tendencia de corto plazo |
| EMA 30 | Tendencia intermedia |
| SMA 50 | Tendencia principal |
| SMA 100 | Soporte dinámico |
| SMA 200 | Tendencia de largo plazo |

No existe una combinación universal.

Lo importante es utilizar siempre el mismo criterio.

---

# Precio sobre la SMA 200

```
Precio

↑

SMA 200

────────────────────
```

Interpretación:

- contexto estructural alcista;
- mayor probabilidad de estrategias largas;
- menor interés por estrategias bajistas.

---

# Precio bajo la SMA 200

```
SMA 200

────────────────────

↓

Precio
```

Interpretación:

- contexto estructural débil;
- prudencia con Cash Secured Puts;
- posible prioridad a la preservación del capital.

---

# Cruce de medias

Los cruces deben interpretarse como confirmaciones.

Nunca como señales aisladas.

Ejemplo.

```
EMA 20

↑

Cruza SMA 50

↓

Fortaleza creciente
```

La decisión debe validarse mediante:

- volumen;
- estructura;
- soportes;
- resistencias.

---

# Pullback sobre la media

Uno de los escenarios más interesantes.

```
Impulso

↓

Retroceso

↓

EMA 20

↓

Reanudación
```

Estrategias posibles:

- Compra directa.
- LEAPS.
- Cash Secured Put.

---

# Alejamiento excesivo

Cuando el precio se separa mucho de las medias:

```
Media

────────────

Precio

                ↑↑↑
```

Puede aumentar la probabilidad de una corrección.

En este contexto conviene evitar perseguir el precio.

---

# Integración con opciones

| Situación | Estrategia preferente |
|------------|----------------------|
| Tendencia fuerte | LEAPS |
| Pullback | CSP |
| Lateral | Covered Call |
| Debilidad | Esperar o cubrir |

---

# Error frecuente

Operar únicamente porque:

```
El precio toca la media.
```

Las medias no son soportes automáticos.

Necesitan confirmación mediante el comportamiento del precio.

---

# Checklist

□ Tendencia principal identificada.

□ Relación con SMA 200.

□ Volumen acompaña.

□ Wyckoff coherente.

□ Estrategia compatible.
