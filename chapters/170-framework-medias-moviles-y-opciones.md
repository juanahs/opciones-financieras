# Capítulo 170 — Framework de Medias Móviles Aplicado a Opciones



---

# Introducción

Las medias móviles constituyen uno de los filtros de tendencia más utilizados por gestores institucionales.

Su función principal no consiste en generar señales.

Su función consiste en definir el contexto.

Las opciones deben adaptarse a ese contexto.

---

# Media de 200 sesiones

Representa habitualmente la tendencia primaria.

```
Precio

>

MM200
```

Sesgo alcista dominante.

---

```
Precio

<

MM200
```

Mayor prudencia con estrategias alcistas.

---

# Media de 50 sesiones

Permite seguir la tendencia intermedia.

Los retrocesos hacia esta media suelen convertirse en zonas de interés para el Swing Trading.

---

# Pullback

```
Impulso

↓

Retroceso

↓

MM50

↓

Reanudación
```

Alternativas.

- Compra directa.
- CSP.
- LEAPS.

---

# Cruces

Los cruces de medias no deben utilizarse de forma aislada.

Siempre deben validarse mediante:

- estructura;
- volumen;
- volatilidad.

---

# Integración

```
MM200

↓

MM50

↓

Wyckoff

↓

VSA

↓

Opciones
```

---

# Error frecuente

Comprar únicamente porque el precio toca una media móvil.

Las medias representan zonas.

No garantías.

---

# Conclusión

Las medias móviles ayudan a determinar el entorno.

Las opciones permiten ejecutar la decisión con mayor eficiencia.
