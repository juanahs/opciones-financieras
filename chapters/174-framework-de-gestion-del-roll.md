# Capítulo 174

# Framework Profesional para Decidir un Roll

---

# Introducción

El Roll es una de las herramientas más útiles del mercado de opciones.

También es una de las más mal utilizadas.

No debe emplearse para ocultar pérdidas.

Debe utilizarse para adaptar una posición cuando la hipótesis original continúa siendo válida.

---

# Definición

Un Roll consiste en:

```
Cerrar

posición actual

↓

Abrir

nueva posición

simultáneamente
```

---

# Primera pregunta

Antes de pensar en un Roll.

```
¿La tesis

sigue siendo válida?
```

Si la respuesta es negativa.

No hacer Roll.

Cerrar.

---

# Segunda pregunta

```
¿Qué mejora

el nuevo contrato?
```

Debe mejorar al menos uno de estos aspectos.

- tiempo;
- Strike;
- riesgo;
- liquidez;
- probabilidad.

---

# Cuándo hacer Roll

Ejemplos.

- mantener una CSP sobre una empresa excelente;
- retrasar el vencimiento;
- desplazar el Strike tras un cambio técnico.

---

# Cuándo NO hacerlo

```
Perder dinero

↓

Mover vencimiento

↓

Esperar un milagro
```

Eso no constituye gestión.

Constituye aplazamiento.

---

# Árbol operativo

```
Posición

↓

Cambio contexto

↓

¿Hipótesis válida?

│

├── No

│      ↓

│    Cerrar

│

└── Sí

       ↓

      Evaluar Roll
```

---

# Checklist

□ La tesis continúa vigente.

□ El nuevo contrato mejora la posición.

□ El riesgo permanece controlado.

□ El Roll tiene una justificación objetiva.

---

# Conclusión

Un Roll bien ejecutado mejora una posición.

Un Roll sin fundamento únicamente retrasa una decisión que ya debería haberse tomado.
