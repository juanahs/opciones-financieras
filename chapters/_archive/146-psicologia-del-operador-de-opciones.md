# Psicología del Operador de Opciones

---

# Introducción

Después de cientos de páginas dedicadas a estrategias, Greeks, volatilidad y gestión del riesgo, aparece un aspecto que suele recibir mucha menos atención y, sin embargo, determina una gran parte de los resultados obtenidos.

La psicología.

Las opciones magnifican las emociones porque permiten obtener beneficios o pérdidas importantes utilizando relativamente poco capital.

Precisamente por ello exigen una disciplina superior a la necesaria para comprar acciones.

---

# La ilusión del control

Las opciones ofrecen decenas de combinaciones posibles.

Esto genera una sensación engañosa.

```
Más estrategias

↓

Mayor control
```

La realidad es distinta.

```
Más estrategias

↓

Más decisiones

↓

Más errores potenciales
```

---

# El exceso de confianza

Después de varias operaciones consecutivas con beneficio suele aparecer una sensación peligrosa.

```
"He encontrado un sistema."
```

Normalmente esto conduce a:

- aumentar tamaño;
- asumir más riesgo;
- reducir disciplina.

---

# El miedo al Assignment

Muchos inversores consideran el Assignment como un fracaso.

En realidad:

```
Cash Secured Put

↓

Assignment

↓

Compra de acciones
```

Si ese era el objetivo inicial, el Assignment representa exactamente el éxito del plan.

---

# El miedo a perder una subida

La Covered Call genera un conflicto psicológico habitual.

```
Prima cobrada

↓

Mercado continúa subiendo
```

El inversor siente que ha cometido un error.

No necesariamente.

Debe recordar que:

La operación se diseñó con un beneficio máximo previamente aceptado.

---

# La obsesión por cerrar pronto

Otro comportamiento frecuente.

```
Pequeño beneficio

↓

Cerrar inmediatamente
```

Mientras tanto:

```
Pérdidas

↓

Esperar demasiado
```

Este comportamiento deteriora la esperanza matemática de cualquier sistema.

---

# La disciplina

Los mejores gestores no poseen una capacidad especial para predecir el mercado.

Poseen una extraordinaria capacidad para ejecutar el mismo proceso una y otra vez.

---

# Conclusión

La psicología no sustituye al análisis.

Pero un excelente análisis ejecutado sin disciplina termina produciendo resultados mediocres.
