# Capítulo 135

# Modelo Operativo Profesional para Covered Call

---

# Introducción

La Covered Call suele utilizarse de forma incorrecta.

Muchos inversores venden Calls cada mes de forma automática.

Un gestor profesional únicamente vende una Covered Call cuando mejora la rentabilidad esperada respecto a mantener las acciones sin cobertura.

---

# Objetivo

Monetizar una posición existente sin deteriorar significativamente el potencial alcista.

---

# Proceso

```
Acciones

↓

Analizar tendencia

↓

Analizar resistencia

↓

Analizar IV

↓

Elegir Strike

↓

Gestionar
```

---

# Momento ideal

```
Subida importante

↓

Resistencia

↓

Momentum desacelerándose

↓

IV elevada
```

---

# Momento poco adecuado

```
Ruptura

↓

Nuevo máximo histórico

↓

Volumen creciente
```

En este contexto suele ser preferible mantener toda la exposición alcista.

---

# Selección del Strike

Debe situarse preferentemente:

- por encima de una resistencia;
- por encima del objetivo del Swing;
- donde aceptaríamos vender las acciones.

---

# Gestión

Escenario 1.

```
La Call expira

↓

Conservar acciones

↓

Nueva Covered Call
```

Escenario 2.

```
Assignment

↓

Venta de acciones

↓

Buscar nueva oportunidad
```

Escenario 3.

```
Movimiento explosivo

↓

Analizar Roll
```

---

# Error frecuente

Vender Covered Calls sobre empresas que todavía presentan un enorme potencial alcista.

La prima recibida puede resultar insignificante comparada con el beneficio perdido.

---

# Checklist

□ Beneficio acumulado.

□ Resistencia cercana.

□ IV favorable.

□ Acepto vender las acciones.

□ Riesgo conocido.

---

# Conclusión

La Covered Call debe utilizarse para optimizar una posición existente, nunca para limitar sistemáticamente el crecimiento de una excelente empresa.
