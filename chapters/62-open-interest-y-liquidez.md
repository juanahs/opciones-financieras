# Capítulo 62

# Open Interest, Volumen y Liquidez

---

# Introducción

Una estrategia excelente puede convertirse en una mala operación si se ejecuta sobre una cadena de opciones poco líquida.

Muchos inversores dedican horas a analizar la empresa y apenas unos segundos a comprobar si podrán entrar y salir de la posición con facilidad.

La liquidez forma parte del riesgo.

No es un detalle operativo.

Es una variable crítica en la gestión profesional.

---

# Objetivos

Al finalizar este capítulo el lector será capaz de:

- Interpretar correctamente el Open Interest.
- Diferenciar Open Interest y Volumen.
- Evaluar la liquidez de una cadena de opciones.
- Evitar mercados poco eficientes.

---

# ¿Qué es el Open Interest?

El Open Interest representa el número de contratos abiertos que permanecen vivos.

No mide actividad diaria.

Mide contratos existentes.

Ejemplo.

```
Open Interest

5.200 contratos
```

Significa que existen aproximadamente 5.200 contratos abiertos en ese Strike.

---

# ¿Qué es el volumen?

El volumen mide únicamente los contratos negociados durante la sesión.

```
Hoy

Volumen

350 contratos
```

Mañana volverá a comenzar desde cero.

---

# Diferencias

| Open Interest | Volumen |
|---------------|----------|
| Acumulado | Diario |
| Indica liquidez potencial | Indica actividad reciente |
| Cambia lentamente | Cambia continuamente |

---

# ¿Por qué importa?

Una elevada liquidez suele implicar:

- spreads más reducidos;
- ejecución más eficiente;
- menor coste implícito;
- mayor facilidad para realizar Rolls.

---

# Bid-Ask Spread

Ejemplo.

```
Bid

2,15

Ask

2,18
```

Spread:

```
0,03 $
```

Muy eficiente.

Ahora compare:

```
Bid

1,80

Ask

2,40
```

Spread:

```
0,60 $
```

Aunque la estrategia sea correcta, el coste de entrada ya supone una desventaja importante.

---

# Liquidez mínima

No existe un número universal.

Sin embargo, suelen preferirse:

- Open Interest elevado.
- Volumen diario suficiente.
- Bid-Ask estrecho.

Los tres elementos deben analizarse conjuntamente.

---

# Error habitual

Muchos operadores únicamente observan la prima.

Nunca comprueban:

- liquidez;
- Open Interest;
- spreads.

El coste oculto aparece al intentar cerrar la posición.

---

# Checklist

□ Open Interest suficiente.

□ Volumen diario adecuado.

□ Spread reducido.

□ Posibilidad razonable de ajuste.

□ Mercado eficiente.

---

# Conclusión

Una buena liquidez reduce costes, facilita la gestión y mejora la calidad de ejecución.

Es una ventaja competitiva silenciosa.
