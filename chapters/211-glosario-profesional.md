# Capítulo 211 — Glosario Profesional (A–Z)

Este glosario consolida las entradas técnicas presentes en los capítulos 211–223 en un único recurso A–Z.

# Acciones
Títulos que representan una participación en el capital de una empresa.

# American Style
Opciones que pueden ejercerse en cualquier momento hasta el vencimiento.

# Assignment
Proceso por el cual se asigna el cumplimiento de una obligación derivada de una opción vendida.

# Ask / Bid / Bid-Ask Spread
Ask: precio mínimo solicitado por el vendedor.
Bid: precio máximo ofrecido por el comprador.
Bid-Ask Spread: diferencia entre ambos; indicador de eficiencia de ejecución.

# At The Money (ATM) / In The Money (ITM) / Out Of The Money (OTM)
Definiciones básicas sobre la posición relativa del Strike respecto al precio del subyacente.

# Black-Scholes
Modelo para valorar opciones europeas bajo ciertas hipótesis; referencia práctica aunque con limitaciones.

# Break-even
Precio a partir del cual una posición comienza a generar beneficio al vencimiento.

# Calendar / Time / Horizontal Spread
Estrategia que utiliza distintos vencimientos (normalmente mismo Strike); sensible a Theta y Vega.

# Call / Put
Call: derecho a comprar el subyacente al Strike.
Put: derecho a vender el subyacente al Strike.

# Cash Secured Put (CSP)
Venta de una Put respaldada por efectivo suficiente para adquirir las acciones en caso de assignment.

# Collar / Zero Cost Collar
Cobertura formada por Put comprada y Call vendida; variante "zero cost" busca compensar coste mediante prima.

# Covered Call / Poor Man's Covered Call (PMCC)
Covered Call: venta de Call sobre acciones que ya se poseen.
PMCC: uso de LEAPS ITM combinado con venta de Calls de corto plazo para replicar Covered Call con menor capital.

# Credit Spread / Debit Spread / Vertical Spread
Spreads definidos por diferencias de Strike y/o vencimiento; clasificación según flujo de caja inicial.

# Delta / Gamma / Vega / Theta / Rho
Definición de las Greeks y su uso para medir sensibilidades: Delta (precio), Gamma (velocidad de Delta), Vega (volatilidad), Theta (paso del tiempo), Rho (tipos de interés).

# Diagonal / Ratio / Backspread / Butterfly / Iron Condor / Iron Butterfly
Breve definición de estrategias multi-pata y su objetivo de riesgo/beneficio.

# Early Assignment / Early Exercise / Exercise / Expiration Date
Conceptos relacionados con ejercicio y asignación antes o en vencimiento.

# Expected Move / Implied Move / Volatility Crush / Skew / Smile / Term Structure
Conceptos y riesgos asociados a la volatilidad implícita y su estructura temporal.

# Gamma Scalping / Hedging / Hedging Cost
Técnicas avanzadas de cobertura y su coste; gamma scalping para monetizar cambios en Gamma.

# Implied Volatility (IV) / Historical Volatility / Realized Volatility
Diferencias entre volatilidad implícita y volatilidad histórica/realizada.

# Index Options / Option Chain / Open Interest / Volume
Herramientas de mercado: cadenas de opciones, liquidez (Open Interest) y volumen de negociación.

# LEAPS / Limit Order / Liquidity / Market Maker
LEAPS: opciones de largo plazo; orden límite; criterios de liquidez; papel del Market Maker.

# Margin / Portfolio Margin / Notional Value
Garantías y metodologías para calcular requisitos de margen y riesgo nocional.

# Net Credit / Net Debit / Premium / Cost Basis
Términos contables y de coste de las posiciones.

# Pin Risk
Riesgo asociado a vencimientos con precio cercano al Strike que puede provocar incertidumbre en assignment.

# Probability / Probability Lab / Expected Move
Herramientas y métricas para estimar probabilidades y movimiento implícito del mercado.

# Quant / Risk Graph / Return on Capital / Return on Risk
Conceptos cuantitativos y métricas para evaluar estrategias y riesgos.

# Roll
Cerrar y abrir posiciones para modificar Strike/vencimiento; técnica habitual de gestión.

# Scalping / Trader / Trading Plan
Diferenciación entre estilos y la importancia del plan de trading.

# Strike / Support / Resistance
Conceptos técnicos para selección de strikes y niveles relevantes.

# Synthetic Position / Synthetic Long / Conversion / Box Spread
Posiciones sintéticas y estrategias de arbitraje/replicación.

# Underlying / Unrealized Profit / Write Option / Yield Enhancement
Términos finales sobre subyacentes, beneficios no realizados y venta de opciones.

Nota: este glosario es una consolidación de las entradas originales. Para términos más avanzados o ejemplos prácticos, consultar los capítulos específicos del manual.

# Acciones

Títulos que representan una participación en el capital de una empresa.

# American Style

Proceso mediante el cual OCC asigna el cumplimiento de una obligación derivada de una opción vendida.

Precio mínimo solicitado por el vendedor de un contrato.

# At The Money (ATM)

Strike muy próximo al precio del activo subyacente.

# Automatic Exercise

Ejercicio automático de opciones ITM al vencimiento según las reglas de la cámara de compensación, salvo instrucciones en sentido contrario del titular.

# Annualized Return

Rentabilidad expresada en términos anuales para facilitar comparaciones entre inversiones con distintos horizontes temporales.

# Adjusted Cost Basis

Coste de adquisición ajustado tras determinadas operaciones corporativas o eventos que modifican la base fiscal de una posición.
