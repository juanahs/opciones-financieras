# Capítulo 94

# Protective Put Avanzada: Seguro para una Cartera de Acciones

---

# Introducción

Todo inversor acepta contratar un seguro para su vivienda aunque espere no utilizarlo nunca.

Sin embargo, muchos consideran innecesario proteger una cartera valorada en cientos de miles de euros.

La Protective Put cumple exactamente esa función.

No pretende aumentar la rentabilidad.

Pretende limitar pérdidas extraordinarias.

Este cambio de mentalidad es fundamental.

Un gestor profesional no intenta adivinar el futuro.

Diseña la cartera para sobrevivir a escenarios adversos.

---

# Objetivos

Al finalizar este capítulo el lector será capaz de:

- Determinar cuándo merece la pena comprar protección.
- Calcular el coste del seguro.
- Elegir Strike y vencimiento.
- Integrar la cobertura dentro de una cartera patrimonial.

---

# Filosofía

La pregunta correcta no es:

```
¿Voy a ganar dinero con la Put?
```

Sino:

```
¿Cuánto estoy dispuesto a pagar
por limitar una pérdida extrema?
```

---

# Estructura

```
Comprar acciones

+

Comprar Put
```

La Put establece un precio mínimo aproximado de venta durante su vigencia.

---

# ¿Cuándo utilizarla?

Especialmente cuando:

- existen fuertes beneficios acumulados;
- aumenta la incertidumbre;
- se aproxima un evento importante;
- el inversor no desea vender las acciones.

---

# ¿Cuándo evitarla?

Generalmente resulta poco eficiente cuando:

- la IV es extremadamente alta;
- la cartera es muy pequeña;
- el horizonte temporal es muy corto.

---

# Coste

Toda protección tiene un coste.

Ese coste aparece principalmente como:

- Theta negativo.
- Prima pagada.

Por ello conviene proteger únicamente cuando el riesgo lo justifica.

---

# Selección del Strike

Existen tres enfoques habituales.

Conservador.

```
ATM
```

Equilibrado.

```
Ligeramente OTM
```

Económico.

```
Muy OTM
```

Cada alternativa implica un equilibrio distinto entre coste y nivel de protección.

---

# Riesgos

- coste recurrente;
- pérdida de valor temporal;
- exceso de cobertura.

---

# Checklist

□ Quiero mantener las acciones.

□ Riesgo extraordinario identificado.

□ Coste asumible.

□ Vencimiento adecuado.

□ Strike coherente.

---

# Conclusión

La Protective Put debe considerarse un seguro patrimonial.

Su éxito no consiste en generar beneficios.

Consiste en evitar pérdidas difíciles de recuperar.
