# Capítulo 111 — Capítulo 111

# Paridad Put-Call

---

# Introducción

La Paridad Put-Call constituye uno de los pilares matemáticos del mercado de opciones.

No es una estrategia.

No es una opinión.

Es una relación financiera que debe cumplirse para evitar oportunidades de arbitraje.

Gran parte de las estrategias sintéticas estudiadas anteriormente derivan directamente de esta igualdad.

---

# Objetivos

Al finalizar este capítulo el lector será capaz de:

- Comprender el fundamento de la Paridad Put-Call.
- Interpretar posiciones sintéticas.
- Entender por qué diferentes estructuras producen exposiciones equivalentes.

---

# La igualdad fundamental

Para opciones europeas sobre acciones sin dividendos:

```
Call

-

Put

=

Acción

-

Valor actual

del Strike
```

Esta relación puede reorganizarse para construir múltiples posiciones equivalentes.

---

# Interpretación

La consecuencia práctica es que:

```
Acciones

↓

Pueden replicarse

↓

Mediante opciones
```

Y también:

```
Opciones

↓

Pueden replicarse

↓

Mediante acciones
```

---

# Aplicaciones

La Paridad Put-Call permite construir:

- Synthetic Long.
- Synthetic Short.
- Conversion.
- Reverse Conversion.
- Box Spread.

---

# Importancia

Cuando la igualdad deja de cumplirse aparecen oportunidades de arbitraje.

En mercados líquidos estas diferencias suelen desaparecer rápidamente gracias a la actuación de participantes profesionales.

---

# Integración con el libro

Comprender esta relación permite dejar de ver las estrategias como estructuras independientes.

En realidad, muchas son simplemente distintas formas de representar una misma exposición al riesgo.

---

# Checklist

□ Comprendo la igualdad.

□ Comprendo las posiciones sintéticas.

□ Entiendo el concepto de arbitraje.

---

# Conclusión

La Paridad Put-Call es el lenguaje común que conecta todas las estrategias de opciones.

Dominarla permite comprender el mercado desde una perspectiva mucho más profunda que la mera memorización de estrategias.
