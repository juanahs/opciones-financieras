# Capítulo 169

# Framework RSI Aplicado a Opciones

---

# Introducción

El RSI no genera señales de compra o venta por sí solo.

Su utilidad consiste en medir el momentum del movimiento.

Cuando se combina con estructura de mercado, Wyckoff y VSA, ayuda a decidir qué estrategia con opciones resulta más eficiente.

Nunca debe utilizarse de forma aislada.

---

# Principio fundamental

El RSI responde a la pregunta:

```
¿Cómo de fuerte
es el movimiento actual?
```

No responde:

```
¿Debo comprar?
```

---

# RSI en tendencia alcista

Durante tendencias fuertes es normal observar:

```
RSI

>

60
```

Esto no implica sobrecompra.

Puede reflejar fortaleza institucional.

---

# RSI en tendencia bajista

En mercados bajistas es habitual encontrar:

```
RSI

<

40
```

No implica automáticamente oportunidad de compra.

---

# Divergencia alcista

```
Precio

↓

Nuevo mínimo

↓

RSI

↓

Mínimo superior
```

Puede anticipar agotamiento vendedor.

Si además aparecen:

- Spring;
- Stopping Volume;
- soporte relevante;

las estrategias alcistas comienzan a ganar atractivo.

---

# Divergencia bajista

```
Precio

↓

Nuevo máximo

↓

RSI

↓

Máximo inferior
```

Puede justificar prudencia.

No implica necesariamente abrir estrategias bajistas.

---

# Integración

```
RSI

+

Wyckoff

+

VSA

IV

Opciones
```

---

# Conclusión

El RSI no selecciona estrategias.

Únicamente ayuda a evaluar la calidad del contexto técnico.
