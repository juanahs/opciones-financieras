# Capítulo 157

# Métricas Profesionales de Rendimiento

---

# Introducción

Uno de los errores más comunes entre los inversores en opciones consiste en evaluar una estrategia únicamente por el beneficio obtenido.

Un gestor profesional rara vez comienza observando la rentabilidad.

Antes analiza cómo se ha conseguido.

La calidad del proceso siempre tiene prioridad sobre el resultado aislado.

---

# Beneficio absoluto

La métrica más simple.

```
Beneficio

=

Ingresos

-

Pérdidas
```

Es útil.

Pero insuficiente.

---

# Rentabilidad sobre capital

La pregunta correcta no es:

```
¿Cuánto he ganado?
```

Sino:

```
¿Cuánto he ganado

respecto al capital

que he inmovilizado?
```

---

# Rentabilidad anualizada

Permite comparar estrategias con vencimientos distintos.

Ejemplo.

```
5 %

en

30 días

≠

5 %

en

180 días
```

---

# Esperanza matemática

La métrica más importante.

```
Esperanza

=

Probabilidad × Ganancia

-

Probabilidad × Pérdida
```

Una estrategia puede ganar el 80 % de las veces y seguir siendo mala si las pérdidas son desproporcionadas.

---

# Profit Factor

```
Beneficios Totales

/

Pérdidas Totales
```

Interpretación.

| Valor | Interpretación |
|--------|----------------|
| <1 | Sistema perdedor |
| 1-1,5 | Débil |
| 1,5-2 | Bueno |
| >2 | Muy sólido |

---

# Drawdown

Nunca debe ignorarse.

Pregunta.

```
¿Cuál fue la mayor pérdida
desde un máximo anterior?
```

Muchos sistemas rentables fracasan porque generan Drawdowns psicológicamente insoportables.

---

# Ratio beneficio/riesgo

Debe calcularse antes de abrir cada operación.

No después.

---

# Consistencia

Analizar.

- meses positivos;
- meses negativos;
- estabilidad de resultados;
- dependencia de pocas operaciones.

---

# Conclusión

La rentabilidad explica cuánto se ha ganado.

Las métricas profesionales explican si merece la pena seguir utilizando ese proceso.
