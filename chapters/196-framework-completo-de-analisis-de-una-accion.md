# Capítulo 196 — Framework Completo para Analizar una Acción antes de Operar Opciones



---

# Introducción

Este capítulo resume todo el proceso desarrollado a lo largo del libro en un único procedimiento operativo.

Su objetivo es responder una única pregunta:

> **¿Qué debo hacer con esta empresa hoy?**

No pretende encontrar oportunidades.

Pretende descartar operaciones de baja calidad.
