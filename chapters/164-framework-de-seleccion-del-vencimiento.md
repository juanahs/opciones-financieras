# Capítulo 164 — Framework Profesional para Seleccionar el Vencimiento



---

# Introducción

Muchos operadores seleccionan el vencimiento observando únicamente la prima.

Un gestor profesional comienza preguntándose cuánto tiempo necesita para que su hipótesis tenga una probabilidad razonable de desarrollarse.

El vencimiento debe adaptarse a la tesis.

Nunca al contrario.

---

# Pregunta inicial

```
¿Cuánto tiempo

necesita

esta idea?
```

# Factores

Nunca seleccionar un vencimiento sin revisar.

- Earnings.
- Dividendos.
- reuniones de bancos centrales.
- resultados trimestrales.
- vencimientos cercanos.

---

# Relación con Theta

```
Poco tiempo

↓

Theta elevada

------------------

Mucho tiempo

↓

Theta reducida
```

---

# Relación con Vega

Los vencimientos largos responden más intensamente a cambios en la volatilidad.

---

# Error habitual

Comprar opciones con un vencimiento muy corto esperando que el mercado confirme una tendencia que probablemente necesite varios meses.

---

# Regla práctica

El vencimiento debe conceder tiempo suficiente para que la hipótesis tenga margen para desarrollarse sin que Theta se convierta en el principal enemigo.

---

# Conclusión

El tiempo constituye un activo.

Elegir correctamente el vencimiento significa comprar el tiempo estrictamente necesario.

Ni más.

Ni menos.
