# Capítulo 122 — Framework Profesional para Seleccionar una Estrategia con Opciones



---

# Introducción

Uno de los mayores errores del inversor particular consiste en pensar:

> "¿Qué estrategia de opciones puedo utilizar?"

Un gestor profesional nunca empieza por la estrategia.

Empieza por el problema.

La estrategia aparece como consecuencia.

La diferencia parece sutil, pero cambia completamente la forma de invertir.

---

# El proceso de decisión

Todo análisis debe seguir exactamente el mismo orden.

```
Empresa

↓

Análisis fundamental básico

↓

Análisis técnico

↓

Contexto del mercado

↓

Volatilidad

↓

Objetivo del inversor

↓

Selección de estrategia
```

Si este orden se altera, aumenta la probabilidad de construir una posición incoherente.

---

# Paso 1. ¿Quiero poseer las acciones?

Esta es la pregunta más importante de todo el libro.

```
Sí

↓

Continuar

----------------

No

↓

Descartar CSP

Descartar Wheel

Descartar PMCC

Descartar Covered Call
```

Nunca debe venderse una Put sobre una empresa que no estaríamos dispuestos a mantener durante años.

# Paso 3. ¿Cómo está la volatilidad?

```
IV Baja

↓

Comprar opciones

----------------

IV Alta

↓

Vender opciones

----------------

↓

```

La volatilidad nunca decide por sí sola.

Simplemente inclina la balanza.

---

# Paso 4. ¿Cuál es el objetivo?

| Objetivo | Estrategias principales |
|-----------|------------------------|
| Comprar acciones | CSP |
| Cobrar primas | Covered Call |
| Sustituir acciones | LEAPS / ZEBRA |
| Limitar riesgo | Protective Put |
| Reducir capital | Bull Put Spread |
| Cobertura parcial | Collar |

---

# Paso 5. ¿Cuál es el peor escenario?

Antes de enviar una orden debe existir una respuesta clara.

```
¿Qué ocurre si todo sale mal?
```

Si la respuesta es:

```
"No lo sé"
```

La operación todavía no está preparada.

---

# Checklist

□ Empresa excelente.

□ Contexto técnico favorable.

□ IV analizada.

□ Objetivo definido.

□ Riesgo máximo conocido.

□ Plan de salida preparado.

---

# Conclusión

La mayoría de los errores no aparecen por elegir una mala estrategia.

Aparecen por elegir la estrategia correcta para el problema equivocado.
