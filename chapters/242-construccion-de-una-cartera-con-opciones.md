# Capítulo 242

# Construcción de una Cartera mediante Opciones

---

# Objetivo

Utilizar las opciones como complemento de una cartera de acciones.

No como sustituto de una estrategia de inversión.

---

# Ejemplo de asignación

| Activo | Peso orientativo |
|---------|-----------------:|
| Acciones | 60 % |
| ETFs | 20 % |
| LEAPS | 10 % |
| CSP | 5 % |
| Coberturas | 5 % |

---

# Principios

- diversificación;
- liquidez;
- riesgo limitado;
- horizonte de largo plazo.

---

# Gestión

Revisar periódicamente.

- concentración;
- exposición sectorial;
- volatilidad;
- capital comprometido.

---

# Error habitual

Acumular demasiadas posiciones con un comportamiento muy similar.

---

# Conclusión

Una cartera robusta depende más de la gestión del conjunto que del éxito de una única operación.
