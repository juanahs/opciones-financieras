# Capítulo 207 — Checklist Profesional para Realizar un Roll



---

# Objetivo

Evitar Rolls impulsivos.

---

# Preguntas

□ ¿La tesis continúa vigente?

□ ¿El nuevo contrato mejora objetivamente la posición?

□ ¿El riesgo permanece controlado?

□ ¿La liquidez sigue siendo suficiente?

□ ¿El nuevo Strike tiene sentido técnico?

□ ¿El nuevo vencimiento concede tiempo suficiente?

□ ¿El Roll reduce el riesgo o únicamente retrasa una pérdida?

---

# Decisión

```
Todas

las respuestas

afirmativas

↓

Roll

---------------

Alguna

respuesta

negativa

↓

Cerrar
```

---

# Error habitual

Confundir un Roll con una obligación.

Ninguna posición exige ser rolada.

---

# Conclusión

El Roll constituye una herramienta de gestión.

Nunca una estrategia para evitar reconocer un error.
