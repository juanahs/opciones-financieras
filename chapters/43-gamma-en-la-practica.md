# Capítulo 43

# Gamma en la práctica

---

# Introducción

Gamma suele describirse como "la derivada de Delta".

Aunque matemáticamente correcto, este enfoque resulta poco útil para un inversor.

Desde una perspectiva de gestión patrimonial es preferible entender Gamma como la velocidad a la que cambia la exposición direccional.

---

# ¿Qué mide Gamma?

Delta responde:

```
Si la acción sube 1 €...

¿cuánto cambia la opción?
```

Gamma responde:

```
Si la acción vuelve a subir...

¿cómo cambia ahora la Delta?
```

---

# Ejemplo

```
Delta inicial

0,45

Gamma

0,06
```

Tras una subida aproximada de un euro:

```
Nueva Delta

0,51
```

La sensibilidad aumenta.

---

# Gamma elevada

Características:

- cambios rápidos;
- mayor aceleración;
- mayor incertidumbre;
- mayor necesidad de seguimiento.

---

# Gamma reducida

Características:

- comportamiento más estable;
- menor sensibilidad;
- gestión más sencilla.

---

# ¿Cuándo aumenta?

Gamma suele alcanzar sus valores máximos cuando:

- la opción está ATM;
- queda poco tiempo hasta el vencimiento.

---

# Consecuencias

Una posición aparentemente tranquila puede cambiar rápidamente de comportamiento durante los últimos días antes del vencimiento.

Por este motivo muchos gestores reducen exposición antes de esa fase.

---

# Estrategias

Alta Gamma:

- Long Call ATM.
- Long Put ATM.

Baja Gamma:

- LEAPS profundas ITM.
- Covered Calls alejadas del dinero.

---

# Integración con Swing Trading

Si el análisis técnico anticipa un movimiento lento durante varias semanas, una Gamma excesivamente elevada puede no ser deseable.

En cambio, cuando se espera una ruptura explosiva, una Gamma alta puede acelerar el beneficio.

---

# Conclusión

Gamma determina la rapidez con la que cambia el riesgo.

No modifica únicamente el beneficio potencial.

También modifica la estabilidad de la posición.
