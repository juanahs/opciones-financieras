# Capítulo 86 — Capítulo 86

# Caso Práctico Completo: Microsoft

---

# Introducción

Microsoft representa uno de los mejores ejemplos de empresa apta para integrar opciones financieras dentro de una cartera de largo plazo.

Presenta habitualmente:

- elevada liquidez;
- gran capitalización;
- opciones muy líquidas;
- spreads reducidos;
- fuerte seguimiento institucional.

Precisamente por ello es una excelente candidata para Cash Secured Puts, Covered Calls y LEAPS.

---

# Objetivos

Aprender a analizar una empresa desde cero utilizando el proceso completo desarrollado durante este libro.

- soporte horizontal;
