# Capítulo 60

# Soportes, Resistencias y Selección de Strikes

---

# Introducción

El Strike no debe elegirse observando la cadena de opciones.

Debe elegirse observando el gráfico.

La cadena únicamente permite ejecutar una decisión tomada previamente mediante análisis técnico.

---

# Objetivos

- Relacionar niveles técnicos con Strikes.
- Evitar Strikes arbitrarios.
- Integrar probabilidades y estructura.

---

# Soportes

Un soporte representa una zona donde históricamente apareció demanda.

```
Precio

↓

Soporte

────────────
```

Una Cash Secured Put suele tener mucho más sentido cuando su Strike coincide con un soporte relevante.

---

# Resistencias

Una resistencia representa una zona donde históricamente apareció oferta.

```
Resistencia

────────────

↓

Precio
```

Covered Calls situadas cerca de resistencias suelen mantener una buena coherencia técnica.

---

# Soportes dinámicos

No todos los soportes son horizontales.

También existen:

- SMA 50;
- SMA 200;
- directrices;
- canales.

---

# Confluencias

Cuantos más elementos coincidan:

- soporte;
- media;
- volumen;
- LPS;
- divergencia.

Mayor interés puede tener el Strike.

---

# Ejemplo

Microsoft

```
Resistencia

540 $

↓

Covered Call

540
```

La decisión resulta mucho más sólida que seleccionar un Strike simplemente porque ofrece mayor prima.

---

# Error habitual

```
Prima alta

↓

Strike elegido

↓

Después

↓

Buscar explicación técnica
```

El proceso correcto es exactamente el contrario.

---

# Árbol de decisión

```
¿Deseo comprar?

↓

Buscar soporte

↓

Elegir Strike

-----------------------

¿Deseo vender?

↓

Buscar resistencia

↓

Elegir Strike
```

---

# Checklist

□ Strike relacionado con el gráfico.

□ Existe soporte o resistencia.

□ Liquidez adecuada.

□ Delta coherente.

□ Riesgo aceptado.

---

# Conclusión

Los mejores Strikes suelen encontrarse donde el análisis técnico ya identificó una ventaja estadística.
