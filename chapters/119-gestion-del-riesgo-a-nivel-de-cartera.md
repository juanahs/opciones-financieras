# Capítulo 119

# Gestión del Riesgo a Nivel de Cartera

---

# Introducción

La mayoría de los inversores analizan cada operación por separado.

Los gestores profesionales hacen exactamente lo contrario.

La unidad de análisis no es la operación.

Es la cartera completa.

Una posición excelente puede convertirse en una mala decisión si aumenta excesivamente el riesgo agregado.

---

# Objetivos

Al finalizar este capítulo el lector será capaz de:

- Analizar el riesgo global.
- Medir la concentración.
- Controlar la exposición agregada.
- Evitar riesgos ocultos.

---

# Pensar como un gestor

Supongamos la siguiente cartera.

| Empresa | Estrategia |
|----------|------------|
| Apple | CSP |
| Microsoft | LEAPS |
| NVIDIA | Acciones |
| AMD | Bull Put Spread |
| Broadcom | Covered Call |

Muchos inversores creen que están diversificados.

En realidad:

```
Tecnología

↓

Semiconductores

↓

Alta correlación
```

---

# Diversificación real

Una cartera debe diversificarse por:

- sectores;
- países;
- estilos;
- duración;
- volatilidad.

No únicamente por número de posiciones.

---

# Riesgo agregado de Delta

Ejemplo.

| Posición | Delta |
|----------|--------|
| Apple | +55 |
| Microsoft | +82 |
| NVIDIA | +100 |
| AMD | +36 |

Delta total.

```
273
```

La cartera se comporta aproximadamente como 273 acciones largas.

---

# Riesgo de Vega

Muchas LEAPS simultáneas generan una exposición importante a Vega.

Si la volatilidad implícita cae de forma generalizada:

```
Mercado estable

↓

Caída IV

↓

Pérdida simultánea
```

Aunque el precio apenas cambie.

---

# Riesgo temporal

Concentrar demasiados vencimientos en la misma fecha incrementa el riesgo operativo.

Es preferible escalonar.

```
Septiembre

↓

Octubre

↓

Diciembre

↓

Marzo
```

---

# Liquidez estratégica

Una cartera completamente invertida pierde flexibilidad.

La liquidez permite:

- aceptar Assignments;
- aprovechar correcciones;
- reducir estrés.

---

# Checklist

□ Riesgo sectorial.

□ Delta agregada.

□ Vega agregada.

□ Vencimientos distribuidos.

□ Liquidez suficiente.

---

# Conclusión

La calidad de una cartera no depende únicamente de la calidad de cada posición.

Depende de cómo interactúan entre sí.
