# Capítulo 178 — Capítulo 178

# Framework de Mejora Continua

---

# Introducción

Un gestor profesional nunca considera terminado su sistema de inversión.

Los mercados evolucionan.

Las empresas evolucionan.

Las herramientas evolucionan.

Por tanto, el proceso también debe evolucionar.

La mejora continua no consiste en cambiar constantemente de estrategia.

Consiste en perfeccionar lentamente un sistema ya probado.

---

# Ciclo PDCA

La mejora continua puede resumirse mediante un ciclo sencillo.

```
Plan

↓

Do

↓

Check

↓

Act
```

---

# Plan

Definir un único aspecto que se desea mejorar.

Ejemplos.

- selección de empresas;
- elección del Strike;
- gestión del riesgo;
- disciplina.

---

# Do

Aplicar ese cambio durante un número suficiente de operaciones.

Nunca modificar varias variables simultáneamente.

---

# Check

Analizar.

- resultados;
- consistencia;
- errores;
- impacto sobre el riesgo.

---

# Act

Si la mejora funciona.

```
Incorporarla

↓

Al proceso
```

Si no funciona.

```
Eliminarla

↓

Volver

↓

Al método anterior
```

---

# Regla

Cambiar lentamente.

Aprender rápidamente.

---

# Conclusión

La ventaja competitiva de un gestor no surge de encontrar una estrategia secreta.

Surge de mejorar continuamente un proceso sólido.
