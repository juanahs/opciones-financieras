# Capítulo 64

# Cómo Leer una Option Chain Profesionalmente

---

# Introducción

La Option Chain es el centro operativo del mercado de opciones.

Sin embargo, muchos inversores la interpretan únicamente como una lista de precios.

Un gestor profesional extrae mucha más información.

Cada columna ayuda a responder una pregunta distinta.

---

# Objetivos

Al finalizar este capítulo el lector será capaz de:

- Leer una cadena de opciones.
- Seleccionar contratos con criterio.
- Interpretar la información relevante.
- Detectar problemas de liquidez.

---

# Estructura

```
CALLS

Bid

Ask

Last

Volume

Open Interest

IV

Delta

Gamma

Theta

Vega

Strike

PUTS
```

---

# Strike

Representa el precio de ejercicio.

Debe elegirse utilizando el gráfico.

No la prima.

---

# Bid

Precio máximo que ofrece actualmente un comprador.

---

# Ask

Precio mínimo solicitado por un vendedor.

---

# Last

Último precio negociado.

No siempre representa el valor actual de mercado.

---

# Volumen

Actividad negociada durante la sesión.

---

# Open Interest

Contratos abiertos.

Permite estimar liquidez potencial.

---

# Volatilidad Implícita

Indica la incertidumbre descontada por el mercado.

Debe analizarse junto con:

- IV Rank.
- IV Percentile.

---

# Greeks

La cadena muestra habitualmente:

- Delta.
- Gamma.
- Theta.
- Vega.

Cada una ayuda a comprender el comportamiento futuro del contrato.

---

# Flujo de trabajo

```
Gráfico

↓

Escenario

↓

Vencimiento

↓

Strike

↓

Liquidez

↓

Greeks

↓

Operación
```

---

# Error habitual

Abrir primero la cadena y buscar una prima atractiva.

El proceso correcto comienza siempre por el análisis técnico.

---

# Checklist

□ Empresa analizada.

□ Escenario definido.

□ Strike seleccionado.

□ Vencimiento correcto.

□ Liquidez adecuada.

□ Greeks revisadas.

---

# Conclusión

La Option Chain no decide la operación.

Simplemente proporciona las herramientas para ejecutarla de forma eficiente.
