# Capítulo 72

# Roll de Posiciones

---

# Introducción

Uno de los conceptos más importantes en la gestión profesional de opciones es el Roll.

Muchos inversores lo interpretan erróneamente como una forma de evitar pérdidas.

No lo es.

Un Roll consiste únicamente en sustituir una posición por otra distinta.

Su utilidad dependerá de si mejora objetivamente el perfil riesgo-beneficio.

---

# Objetivos

Al finalizar este capítulo el lector será capaz de:

- Comprender qué significa realizar un Roll.
- Saber cuándo tiene sentido.
- Identificar cuándo no debe realizarse.
- Integrarlo dentro de un plan de gestión.

---

# Definición

```
Cerrar

↓

Posición actual

↓

Abrir

↓

Nueva posición
```

Ambas operaciones suelen ejecutarse simultáneamente.

---

# Tipos de Roll

## Roll temporal

Se mantiene el mismo Strike.

Se modifica el vencimiento.

---

## Roll vertical

Se modifica el Strike.

Se mantiene el vencimiento.

---

## Roll diagonal

Cambian:

- Strike.
- Vencimiento.

---

# ¿Cuándo tiene sentido?

Cuando:

- la hipótesis continúa vigente;
- mejora el perfil de riesgo;
- aumenta la probabilidad de éxito.

---

# ¿Cuándo NO?

Nunca debería utilizarse simplemente para:

```
Esconder

una pérdida.
```

Un Roll no convierte una mala operación en una buena inversión.

---

# Ejemplo

Covered Call.

```
Strike

220

↓

Acción

225
```

Posibilidades.

```
Aceptar asignación

o

Roll

a

230

vencimiento posterior
```

La decisión dependerá del objetivo patrimonial.

---

# Costes

Todo Roll implica:

- nuevas comisiones;
- nuevos spreads;
- modificación de Greeks.

---

# Error frecuente

Realizar Rolls indefinidamente.

Una estrategia sin criterio de salida termina convirtiéndose en una fuente permanente de riesgo.

---

# Checklist

□ La hipótesis continúa vigente.

□ El nuevo contrato mejora el perfil.

□ Comprendo el nuevo riesgo.

□ El Roll responde a un plan.

---

# Conclusión

El Roll es una herramienta de gestión.

Nunca un mecanismo para negar la realidad del mercado.
