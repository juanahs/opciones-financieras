# Capítulo 50 — Integración de las Opciones con Swing Trading



---

# Introducción

Este libro no pretende enseñar a vivir de vender opciones.

Tampoco pretende sustituir el análisis técnico.

Las opciones son una herramienta de gestión.

El análisis técnico continúa siendo el elemento que determina:

- cuándo comprar;
- cuándo esperar;
- cuándo reducir riesgo.

Las opciones únicamente modifican la forma de ejecutar esa decisión.

En este capítulo se unifican ambas disciplinas.

---

# El proceso correcto

```
Análisis técnico

↓

Escenario

↓

Estrategia con opciones

↓

Gestión

↓

Resultado
```

Nunca al revés.

---

# Primera pregunta

Antes de pensar en opciones debe responderse:

```
¿Qué espero que haga el precio?
```

No:

```
¿Qué estrategia quiero utilizar?
```

---

# Escenario 1

## Tendencia alcista consolidada

Características:

- máximos crecientes;
- mínimos crecientes;
- volumen saludable;
- medias ascendentes;
- RSI fuerte.

Alternativas.

| Objetivo | Estrategia |
|-----------|------------|
| Comprar acciones | Compra directa |
| Optimizar capital | LEAPS |
| Comprar con descuento | Cash Secured Put |
| Ya posee acciones | Covered Call prudente |

---

# Escenario 2

## Pullback

Características.

```
Tendencia alcista

↓

Corrección

↓

Soporte

↓

Volumen decreciente
```

Opciones posibles.

- Compra directa.
- LEAPS.
- Cash Secured Put.

---

# Escenario 3

## Ruptura de máximos

Cuando aparece una ruptura válida:

- fuerte volumen;
- cierre sólido;
- continuación esperada.

Generalmente tienen sentido:

- acciones;
- LEAPS;
- Bull Call Spread.

Suelen ser menos apropiadas:

Covered Calls muy cercanas.

---

# Escenario 4

## Mercado lateral

Características.

```
Resistencia

────────────

Precio

────────────

Soporte
```

Estrategias posibles.

- Covered Calls.
- Iron Condor.
- Iron Butterfly.
- Cash Secured Put sobre soporte.

---

# Escenario 5

## Tendencia bajista

Si la hipótesis principal continúa siendo bajista:

normalmente la prioridad no consiste en vender Puts.

Puede resultar más razonable:

- esperar;
- reducir exposición;
- utilizar coberturas.

---

# Filosofía

Las opciones nunca deben obligarnos a operar.

Si el gráfico no ofrece ventaja estadística:

```
No operar

también es una decisión.
```

---

# Conclusión

Las opciones deben complementar el Swing Trading.

Nunca sustituirlo.
