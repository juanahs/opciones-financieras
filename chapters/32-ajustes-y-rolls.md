# Capítulo 32

# Ajustes y Rolls

---

# Introducción

Una de las mayores diferencias entre un inversor principiante y un gestor profesional consiste en la forma de gestionar una posición cuando el mercado evoluciona de forma distinta a la prevista.

El principiante suele pensar únicamente en dos posibilidades:

- ganar;
- perder.

El gestor contempla una tercera alternativa:

**adaptar la posición.**

Esta adaptación recibe el nombre de **Roll**.

Un Roll no elimina el riesgo.

No convierte una mala operación en una buena.

Simplemente modifica la estructura temporal, el Strike o ambos para adecuar la posición a la nueva realidad del mercado.

---

# Objetivos

Al finalizar este capítulo el lector será capaz de:

- Comprender qué es un Roll.
- Identificar cuándo merece la pena realizarlo.
- Reconocer cuándo es preferible cerrar la posición.
- Integrar los Rolls en un plan de gestión del riesgo.

---

# ¿Qué es un Roll?

Un Roll consiste en cerrar una opción existente y abrir simultáneamente otra distinta.

Puede modificarse:

- el vencimiento;
- el Strike;
- ambos.

```
Posición actual

↓

Cerrar

↓

Abrir nueva posición

↓

Nueva exposición
```

---

# Tipos de Roll

## Roll temporal

Se mantiene el mismo Strike.

Únicamente se desplaza el vencimiento.

```
Julio

↓

Agosto
```

---

## Roll vertical

Se modifica el Strike.

```
Strike 100

↓

Strike 95
```

---

## Roll diagonal

Se modifican simultáneamente:

- Strike;
- vencimiento.

Es el ajuste más flexible.

---

# ¿Por qué realizar un Roll?

Las razones más habituales son:

- ganar tiempo;
- adaptar el riesgo;
- evitar una asignación inmediata;
- desplazar el objetivo técnico;
- aprovechar un incremento de la volatilidad implícita.

---

# ¿Cuándo NO hacer Roll?

Nunca debe utilizarse un Roll para ocultar una pérdida.

Un Roll únicamente tiene sentido cuando:

- la hipótesis de inversión continúa siendo válida;
- el análisis técnico sigue respaldando la posición;
- la relación riesgo-beneficio continúa siendo favorable.

Si la hipótesis original ha dejado de ser válida, lo correcto suele ser cerrar la operación.

---

# Ejemplo: Cash Secured Put

Supongamos:

```
Precio actual

100 €

Put vendida

95 €

```

Pocos días antes del vencimiento:

```
Precio

94 €
```

El análisis técnico continúa siendo favorable.

Opciones:

```
Aceptar asignación

↓

o

Roll al siguiente vencimiento
```

La decisión dependerá del plan inicial.

---

# Ejemplo: Covered Call

```
Acción

120 €

Call vendida

125 €

```

La acción sube rápidamente hasta:

```
124 €
```

Todavía quedan varias semanas hasta el vencimiento.

Puede estudiarse:

- mantener;
- recomprar;
- realizar Roll a un Strike superior.

---

# Coste del Roll

Un Roll nunca es gratuito.

Puede realizarse:

- por crédito;
- por débito;
- aproximadamente neutro.

Antes de ejecutarlo debe analizarse si mejora realmente la posición.

---

# Integración con Swing Trading

Un Roll debe apoyarse siempre en el gráfico.

No únicamente en la cadena de opciones.

Ejemplo:

```
Spring confirmado

↓

Mayor probabilidad alcista

↓

Quizá no convenga mantener Covered Call cercana.
```

O bien:

```
Nueva resistencia

↓

Puede justificarse un Roll hacia Strike superior.
```

---

# Error habitual

Realizar Rolls indefinidamente únicamente para evitar reconocer una pérdida.

Este comportamiento suele aumentar el riesgo y deteriorar la calidad de la cartera.

---

# Checklist

□ La hipótesis técnica continúa vigente.

□ El Roll mejora realmente la posición.

□ El riesgo permanece controlado.

□ Existe liquidez suficiente.

□ Se comprende el coste del ajuste.

---

# Conclusión

Un Roll no es una herramienta para evitar pérdidas.

Es una herramienta para adaptar posiciones cuando el escenario de inversión continúa siendo válido.
