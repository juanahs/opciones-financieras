# Capítulo 25

# Posiciones Sintéticas

---

# Introducción

Uno de los conceptos más elegantes de las opciones financieras es la posibilidad de replicar económicamente otros activos mediante combinaciones de contratos.

Esto recibe el nombre de posición sintética.

No se trata de una aproximación.

Es una consecuencia directa de la **paridad Put-Call**.

---

# Objetivos

Al finalizar este capítulo el lector comprenderá:

- Qué es una posición sintética.
- Cómo replicar acciones.
- Cómo replicar posiciones cortas.
- Cuándo tiene sentido utilizar estas estructuras.

---

# Long Synthetic Stock

```
Comprar Call

+

Vender Put

Mismo Strike

Mismo vencimiento
```

Resultado económico aproximado:

```
≈

100 acciones
```

---

# Short Synthetic Stock

```
Vender Call

+

Comprar Put
```

Resultado económico aproximado:

```
≈

Venta en corto
```

---

# Aplicaciones

Las posiciones sintéticas permiten:

- optimizar capital;
- adaptar la exposición;
- construir estrategias avanzadas;
- comprender mejor la relación entre opciones y acciones.

---

# Riesgos

Aunque el comportamiento económico sea similar al de una acción, los riesgos operativos son diferentes.

Especialmente:

- asignación;
- liquidez;
- volatilidad;
- margen.

---

# Conclusión

Las posiciones sintéticas constituyen una herramienta conceptual muy poderosa.

Incluso cuando nunca lleguen a utilizarse directamente, comprenderlas permite interpretar con mucha mayor profundidad el funcionamiento del mercado de opciones.
