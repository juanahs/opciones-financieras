# Capítulo 66 — Capítulo 66

# Risk Navigator de Interactive Brokers

---

# Introducción

Una operación aislada rara vez representa el verdadero riesgo de una cartera.

El Risk Navigator permite visualizar el comportamiento conjunto de todas las posiciones.

Es una de las herramientas más potentes de Interactive Brokers para inversores que utilizan derivados.

---

# Objetivos

- Comprender el riesgo agregado.
- Analizar escenarios.
- Interpretar Greeks de cartera.
- Mejorar la toma de decisiones.

---

# Filosofía

No interesa únicamente saber:

```
¿Qué ocurre con esta opción?
```

Interesa conocer:

```
¿Qué ocurre con TODA la cartera?
```

---

# Información disponible

El Risk Navigator permite analizar:

- Delta agregada.
- Gamma agregada.
- Theta agregada.
- Vega agregada.
- Pérdida potencial.
- Beneficio potencial.
- Simulación de escenarios.

---

# Ejemplo

Supongamos:

- Apple.
- Microsoft.
- ASML.
- Covered Calls.
- LEAPS.

Cada posición parece razonable.

Sin embargo:

```
Vega total

muy elevada
```

Una fuerte contracción de IV podría afectar simultáneamente a varias posiciones.

---

# Utilidad

El verdadero valor aparece cuando la cartera contiene:

- varias empresas;
- distintos vencimientos;
- múltiples estrategias.

---

# Error habitual

Analizar únicamente el P/L diario.

El Risk Navigator permite comprender el riesgo antes de que aparezca la pérdida.

---

# Checklist

□ Greeks agregadas revisadas.

□ Escenarios simulados.

□ Concentración sectorial controlada.

□ Riesgo compatible con el patrimonio.

---

# Conclusión

Las decisiones profesionales se toman observando la cartera completa.

No una posición aislada.
