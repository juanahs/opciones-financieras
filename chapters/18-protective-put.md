# Capítulo 18 — Protective Put



---

# Introducción

La Protective Put es el equivalente financiero a contratar un seguro para una cartera de acciones.

No pretende aumentar la rentabilidad.

Pretende limitar pérdidas.

Por este motivo es una herramienta habitual entre gestores patrimoniales durante periodos de incertidumbre.

---

# Construcción

```
Comprar acciones

+

Comprar Put
```

---

# Analogía

```
Casa

↓

Seguro contra incendios

----------------------------

Acciones

↓

Protective Put
```

Mientras el seguro está vigente:

la pérdida máxima queda limitada.

---

# ¿Cuándo utilizarla?

Especialmente cuando:

- se acercan resultados;
- existe incertidumbre política;
- aumenta la volatilidad;
- la cartera acumula importantes beneficios;
- no desea vender por motivos fiscales.

---

# Perfil

```
Beneficio

^

|

|

|

|

|_____

      \

       \

        \_________________

Precio
```

La pérdida queda limitada.

El beneficio continúa siendo prácticamente ilimitado.

---

# Coste

La principal desventaja es evidente.

El seguro tiene un precio.

Si nunca ocurre el evento negativo, la prima se pierde.

---

# Integración con Swing Trading

Especialmente útil cuando:

- existe tendencia alcista;
- aparecen síntomas de distribución;
- no existe confirmación bajista;
- se desea mantener la posición.

---

# Comparación

| Acción | Protective Put |
|---------|----------------|
| Riesgo elevado | Riesgo limitado |
| Sin coste adicional | Pago de prima |
| Beneficio ilimitado | Beneficio casi ilimitado |

---

# Conclusión

Una Protective Put debe considerarse una herramienta de gestión del riesgo y nunca una estrategia destinada a incrementar beneficios.
