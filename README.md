# Opciones Financieras para Inversores en Acciones

> Documentación técnica profesional orientada a inversores de Swing Trading.

---

## Objetivo

Este repositorio constituye una referencia completa sobre la utilización de opciones financieras como herramienta de gestión de una cartera de acciones.

No pretende enseñar a "hacer trading de opciones".

Su objetivo es enseñar cuándo las opciones son superiores a comprar acciones, cuándo no lo son y cómo utilizarlas para mejorar la relación rentabilidad/riesgo.

---

# Público objetivo

Esta documentación está dirigida a inversores que:

- realizan Swing Trading
- utilizan TradingView
- operan principalmente acciones estadounidenses y europeas
- conocen análisis técnico
- utilizan:
  - Wyckoff
  - VSA
  - RSI
  - Medias móviles
  - Precio y volumen
  - Pullbacks
  - Divergencias
  - Spring
  - SOS
  - LPS
- operan mediante Interactive Brokers

---

# Filosofía

Las opciones financieras son un instrumento.

No un fin.

Cada estrategia estudiada responderá siempre:

- ¿Para qué sirve?
- ¿Cuándo utilizarla?
- ¿Cuándo evitarla?
- ¿Qué riesgo tiene?
- ¿Qué alternativa existe?
- ¿Qué ocurre si cambia la volatilidad?
- ¿Qué ocurre si el precio no se mueve?
- ¿Qué ocurre si el movimiento llega demasiado tarde?

# Principios de inversión

1. Preservar capital.
2. Controlar el riesgo antes de buscar rentabilidad.
3. Utilizar opciones únicamente cuando aporten una ventaja objetiva.
4. Evitar complejidad innecesaria.
5. Mantener siempre un plan de salida.
